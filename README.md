How to run:

Python 3.12 or newer. Install the libraries once:

pip install pandas numpy scikit-learn matplotlib seaborn scipy

Then open any week folder and run a file:

python file.py


Data files:

Some weeks need a data file with the code, for example train.csv in week 5.
Keep the data file in the same folder as the code that uses it.
